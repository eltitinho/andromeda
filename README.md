# Andromeda - Tracking and Invoicing System

A Flask-based web application for tracking shipments and generating invoices with authentication.

## Features

- **User Authentication**: Secure login/logout system with session management
- **Tracking System**: Create, view, update, and delete tracking numbers
- **Invoicing**: Generate customizable PDF invoices with multiple items
- **Admin Dashboard**: Manage tracking records and view system status

## Installation

1. Clone the repository
2. Install dependencies:
   ```bash
   pip install -r requirements.txt
   ```

3. Run the application:
   ```bash
   python run.py
   ```

4. Access the application at `http://localhost:5000`

## Testing

Run tests with:
```bash
pytest
```

Test coverage reports are generated in the `htmlcov` directory.
